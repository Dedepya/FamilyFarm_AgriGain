# 🌾 FAMILYFARM (AGRI GAIN)

FAMILYFARM (AGRI GAIN) is a modern, comprehensive, and user-friendly agricultural portal designed to empower farmers with essential digital utilities, financial insights, crop diagnostics, and an integrated marketplace.

---

## ✨ Features

### 1. 📱 Simple One-Time Password (OTP) Sign In
Designed specifically for high accessibility and simplicity:
* **Unified Flow**: Sign up and login are combined into a single intuitive page.
* **Country Code Selector**: Support for global farmers with a customizable dropdown (US, India, UK, Australia, China).
* **Name & Phone Registration**: Register securely with just a full name and mobile number.

### 2. 🛒 Dynamic Agricultural Marketplace
A custom client-side shop tailored to farming supplies:
* **Browse by Category**: Easily navigate products across vital categories (Veggies & Fruits, Rice, Pulses, Cash Crops, Wheat, Maize).
* **Smart Search**: Quickly find seeds, tools, fertilizers, or crops from any page.
* **Instant Cart Operations**: Active global cart context to add items, update quantities on the fly, and calculate prices.

### 3. 💳 Checkout & Simulated Payment Flow
Seamless path to purchase:
* **Itemized Checkout List**: Review your selected items, adjust quantities, or remove items.
* **Secure Simulated Card Payments**: A payment gateway mockup checking form validation with active feedback loaders.

### 4. 🌦️ Weather Forecasts & Advisory
Helping farmers prepare for daily farming tasks through live weather tracking.

### 5. 🐛 Crop Pest Suggestions & Protection
Expert crop disease detection and tailored solution paths to help protect your yields.

### 6. 🏦 Agricultural Loans & Government Schemes
A curated resource catalog displaying regional banking subsidies, interest-free credit, and government insurance programs.

## 🚀 Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed.

### Installation
1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

## 🛠️ Technology Stack
* **Frontend**: React 18+ (TypeScript)
* **Build System**: Vite
* **Styling**: Tailwind CSS
* **Icons**: Lucide React
* **State Management**: React Context API
